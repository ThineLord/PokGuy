# 单手结束与锦标赛规则对齐

RiverLab 当前仍是现金桌与单手牌训练器，不是完整锦标赛管理器。本文件明确区分“一手牌结束”“现金桌训练结束”和“锦标赛结束”，并记录本项目对正式现场规则的采用方式。

## 采用的正式规则来源

- Poker Tournament Directors Association（TDA）当前发布的 2024 Rules Version 1.0；
- 2026 World Series of Poker（WSOP）Official Tournament Rules。

两套规则都把摊牌、底池分配、无人跟注筹码退回、边池和新一手开始视为独立且有顺序的环节。RiverLab 采用其中适用于浏览器无荷官训练器的牌局规则；现场管理、处罚、叫钟和发牌失误等规则不适用。

## 一手牌何时正式结束

一手牌不是在玩家点击 fold、发出河牌或宣布 all-in 的瞬间结束。只有以下结算条件全部满足，状态才可以进入 `complete`：

1. 已确定唯一未弃牌玩家，或已完成所有有资格玩家的摊牌比较；
2. 主池和每一个边池分别确定赢家；
3. 无人跟注的超额投入已退回原玩家；
4. 平分与奇数筹码已经分配；
5. 所有支付已经写入玩家筹码，且支付总额等于本手全部有效投入；
6. 没有待行动玩家，也不会再发公共牌或接受下注。

正式结束有三条路径：

- `uncontested`：只剩一手活牌。该玩家直接获胜，不强制亮牌，也不继续发无意义的公共牌；
- `river-showdown`：河牌下注完成后，所有仍有资格的玩家按最佳五张牌比较；
- `all-in-runout`：所有仍有资格的玩家均已 all-in，且其他有筹码玩家之间已无下注可进行，牌面自动发完后摊牌。

如果只有一名玩家 all-in，但另有两名或更多仍有筹码的玩家可以继续下注，本手不会提前 runout；这些玩家必须完成后续行动。

## 下一手何时开始

正式现场规则通常以发出下一手第一张牌，或自动洗牌机/牌桌设备确认下一手开始作为争议边界。RiverLab 没有现场荷官，因此采用等价的数字边界：

- 只有当前手牌已完整结算，用户才可点击“下一手”；
- 点击后才创建新的 `handId`、移动按钮并重新洗牌发牌；
- 结算期间不能重新买入、重复提交动作或创建下一手；
- 已归零座位不会被静默补回 100BB，也不会参与下一手的按钮和盲注轮转。

## 现金桌训练何时结束

RiverLab 的现金桌训练没有锦标赛冠军。以下任一情况发生时，当前连续训练桌停止发下一手：

- Hero 筹码归零，等待用户明确重新买入或重开；
- 全桌少于两名仍有正筹码的玩家；
- 用户主动离开、重开或切换模式。

重新买入只允许在一手已经结算后执行。它是现金桌训练操作，不会改变刚结束手牌的结算结果。

## 完整锦标赛何时结束

正式锦标赛持续到一名玩家拥有比赛中全部仍在流通的筹码，其他玩家均被淘汰，再根据赛事结构确认最终名次与奖金。多桌锦标赛还涉及盲注级别、ante、座位平衡、破桌、同步手牌（hand-for-hand）、重入/加购、比赛暂停和奖励结构。

这些赛事管理功能不在 RiverLab 当前版本范围内。项目不会把现金桌的手动重新买入误称为锦标赛重入，也不会在没有赛事结构时显示“锦标赛冠军”。

## 规则实现映射

| 正式规则概念         | RiverLab 实现                                                  |
| -------------------- | -------------------------------------------------------------- |
| Cards speak          | 规则引擎枚举 5–7 张牌的所有五张组合，UI 声明不覆盖引擎结果     |
| 唯一活牌获胜         | 立即结算、不强制亮牌、不继续发牌                               |
| All-in 亮牌与 runout | 只有所有下注行动完成后才自动发完；仍可下注时不提前公开         |
| 主池和边池           | 各池独立计算资格、赢家、平分和奇数筹码                         |
| 无人跟注投入         | 不构造单人边池，单独退回原玩家                                 |
| 平分与奇数筹码       | 以 `0.01BB` 为训练筹码单位；余数从按钮左侧起顺时针分给并列赢家 |
| 已弃牌玩家           | 投入仍进入相应底池，但永远没有获奖资格                         |
| Playing the board    | 允许零张底牌成为最佳五张；摊牌时仍展示进入摊牌玩家的完整底牌   |
| 新一手边界           | 完成结算后，由用户点击“下一手”创建新状态                       |

## 本轮新增的结算不变量

- `底池总额 + 无人跟注退回 = 本手累计投入`；
- `所有玩家获奖总额 = 本手累计投入`；
- 完成态不存在待行动玩家；
- 不显示 `0 BB` 的主池、边池、获奖或退回项目；
- 小数筹码统一规范到两位，避免浮点残量制造虚假边池；
- 从翻牌、转牌或河牌开始的训练场景使用已匹配的起始投入，不携带不可能存在的未匹配小盲/大盲。

## 当前不适用的现场规则

- misdeal、死牌、意外亮牌、牌桌用语和荷官错误；
- 叫钟、处罚、离桌玩家和设备使用；
- 多桌平衡、破桌、同步手牌与泡沫期流程；
- 锦标赛盲注级别、ante、重入截止、奖励与淘汰名次。

这些功能若后续加入，必须建立独立的 tournament state machine，不能复用现金桌重新买入逻辑冒充锦标赛流程。

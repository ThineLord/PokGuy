# PokGuy 0.3.0

[English](0.3.0.md) · [简体中文](0.3.0.zh-CN.md) · [更新记录](../../CHANGELOG.md)

发布日期：2026-11-09。本次源码版本完成完整项目测试后提出的 P1–P3 提升项。

## 本地数据更可靠

- **完整备份：** 一个有格式版本的 JSON 文件包含设置、已完成牌局、统计、笔记、训练点评、AI 习惯和界面偏好。
- **先预览再恢复：** 完整校验文件、显示记录数量，再确认或取消。无效、不支持、结构含糊或过大的文件不会替换现有数据。完整恢复会开始新牌局；旧设置导入保留当前牌局，并在确认时合并最新记录。
- **保存失败可见：** 未保存内容保留在内存，持续显示警告，可重试保存或导出救援备份。恢复写入失败会回滚；若回滚不完整，警告保留到数据及偏好完整重试成功。

## 统计和训练反馈更可信

- 现金桌与场景训练独立累计，支持切换统计范围并查看机会分母。旧版混合统计与习惯单独保留，不参与新现金桌 AI 适应。
- 强制全押、没有翻牌前决策的牌局不增加相应机会分母。3-bet 必须存在可加注机会；持续下注必须有实际翻牌行动机会且此前无人下注。
- 信息不足的决策显示 **“未充分评估”**，不再默认给出正面评分。同额下注与全押统一按实际额外投入判断，覆盖河牌全押及全押跟注。
- 新点评记录行动前上下文，并按动作索引准确对应。反馈仍是透明的启发式规则，不是求解器或最优决策证明。

## 移动端与运行环境

- 提高座位姓名与筹码字号，整张座位卡可点击查看完整公开信息。原生弹窗支持焦点管理、Esc 关闭，并隔离扑克快捷键；不会暴露对手暗牌。
- 更新 Next、Vite、Vitest 及兼容的间接依赖，对 image-size 和 Miniflare 依赖做有界修补。审计结果为 **0 critical、0 high、11 条 moderate 包记录**，对应两类残余公告链，已记录可达性。
- 生产构建 Worker 图片接口能将真实 PNG 转为 64 像素 WebP；CI 校验 MIME、字节和解码尺寸，以及非法输入。
- 浏览器测试独占服务器，单元测试限制并发，纯 AI 测试使用 Node 环境；处理测试误连服务和资源争用，不放宽超时。

## 升级与验证

使用 Node 22，运行 `npm ci`。清理站点数据、切换浏览器或地址前先导出完整备份。存储键仍为 `riverlab-poker-v2`，schema 仍为 `2`；新增统计字段自动迁移。备份封装格式版本独立为 `1`。

# PokGuy 0.3.2

[English](0.3.2.md) · [简体中文](0.3.2.zh-CN.md) · [更新记录](../../CHANGELOG.md)

发布日期：2026-11-19。本补丁记录已合并 pull request [#16](https://github.com/ThineLord/PokGuy/pull/16) 的玩家可见训练修复，以及已合并 pull request [#17](https://github.com/ThineLord/PokGuy/pull/17) 的浏览器 CI 修复。存储键 `riverlab-poker-v2` 和 schema 2 不变，无需数据迁移。

## 玩家可见的变化

- 可选行动提示只推荐合法动作。对手已经全下、不能再加注时，强牌建议跟注；仍可以加注或下注的强牌仍建议该动作。下注或加注不合法时，不给出参考尺度。
- 以大盲标注的牌桌金额，在大盲不是一枚筹码时仍使用大盲。底池、下注、跟注、摊牌赢得金额和尺度控件，与座位筹码使用同一单位。尺度控件提交给引擎的仍是筹码数量。非法金额提示使用同一单位；大盲不能整除时，输入框保持 0.01 筹码的步进。
- 大盲为 3 时，座位筹码、复盘上下文和单手盈亏仍显示 0.01 筹码的余数。这些标注使用该手的筹码和该手自己的大盲。已保存的盈亏摘要留在存储中。
- 已弃牌玩家不同的投入层级，不再产生资格集合相同的额外底池。仍在局中且打平的玩家只分割一个可争夺的底池，所以零头筹码只发放一次。按先前层级拆分、已经结算的牌局，在 schema 2 的历史和备份里保留原来的派彩。
- 保存的牌局和备份在 JSON 对象键重排后仍然有效，包括嵌套的底池对象。改变底池金额、资格、份额或派彩仍会被拒绝。
- React、React DOM 和 `react-server-dom-webpack` 从 19.2.8 修补到 19.2.9，对应 GHSA-xqc2-xf4c-x3h3。

## 浏览器 CI

质量任务名称是 `Node 22 quality gate`。Pull request [#17](https://github.com/ThineLord/PokGuy/pull/17) 将浏览器任务从 `Node 22 Chromium E2E gate` 改名为 `Browser E2E gate`（任务 id `chromium-e2e`）。质量任务继续使用 Node 22。浏览器任务在固定的官方 Playwright 镜像上直接运行。容器内通过 `actions/setup-node` 使用 22.x，因此测试套件不使用镜像自带的 Node 24。套件命令是直接的 npm 命令，不使用 `| tee`。容器使用 `options: --init`。Playwright 用 `webServer.gracefulShutdown` 关闭开发服务器。失败时仍上传原来的 `test-results/` 路径，`if-no-files-found: ignore`，保留 7 天。

## 兼容性

存储 schema `2` 和 `riverlab-poker-v2` 不变，无需数据迁移。清理站点数据或更换访问地址前，先导出完整的浏览器备份。

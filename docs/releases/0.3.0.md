# PokGuy 0.3.0

[English](0.3.0.md) · [简体中文](0.3.0.zh-CN.md) · [Changelog](../../CHANGELOG.md)

Released: 2026-11-09. This source release implements the P1–P3 improvements from the full project audit.

## Safer local data

- **Full backup:** export settings, completed hands, statistics, notes, decision reviews, AI habits and interface preferences in one versioned JSON file.
- **Preview before restore:** validate the complete file, preview record counts, then confirm or cancel. Invalid, unsupported, ambiguous or oversized files do not replace current data. Full restore starts a new hand; legacy settings imports preserve the current hand and merge against the latest records.
- **Visible save failures:** keep unsaved data in memory, show a persistent warning, retry saving or export a rescue backup. Failed restore writes roll back; incomplete rollback keeps the warning until a full data/preferences retry succeeds.

## More reliable practice feedback

- Cash and scenario statistics accumulate separately. A scope selector shows each mode and its opportunity denominators. Older mixed totals and habits are preserved separately; they do not influence new cash-table AI adaptation.
- Forced all-in runouts do not inflate preflop action opportunities. Three-bet opportunities require an available raise; continuation bets require an actual checked-to flop opportunity.
- Uncovered decisions are **Not assessed**, rather than automatically positive. Equivalent bets and shoves use the same effective-investment rules, including river shoves and all-in calls.
- New reviews save an immutable pre-action context and match actions by index. This remains a transparent heuristic, not a solver or an optimal-play certificate.

## Mobile and runtime

- Larger seat names/chips and a full-seat touch target open readable public details. Native modal focus, Escape and poker shortcut isolation are covered by browser tests. Hidden opponent cards are not exposed.
- Patch Next/Vite/Vitest and compatible transitive dependencies; apply bounded image-size and Miniflare overrides. Audit results: **0 critical, 0 high, 11 moderate package records**, representing two residual advisory chains with documented reachability.
- Built Worker images now transform a real PNG into a 64px WebP. CI checks actual MIME/bytes/dimensions and invalid inputs, rather than accepting a 200 passthrough.
- Isolated browser servers and bounded unit-test concurrency address the audit's wrong-server and AI-timeout risks without increasing timeouts.

## Upgrade and verify

Use Node 22 and `npm ci`. Export a full backup before changing browser origins or clearing site data. The storage key remains `riverlab-poker-v2` and schema stays `2`; additive statistics fields migrate automatically. The backup envelope has its own format version `1`.

See the [user guide](../user/README.md), [validation commands](../development/README.md), [security assessment](../development/SECURITY_0.3.0.md) and [acceptance record](../development/ACCEPTANCE_0.3.0.md).

GitHub release/tag publication does not deploy a hosted service. Multi-tab conflict prevention, live-hand restoration, physical-device certification and the two residual moderate dependency chains remain explicit limitations.

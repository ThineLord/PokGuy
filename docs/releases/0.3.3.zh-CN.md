# PokGuy 0.3.3

[English](0.3.3.md) · [简体中文](0.3.3.zh-CN.md) · [更新记录](../../CHANGELOG.md)

2026-11-25。这个补丁让跟注显示玩家实际付得出的筹码，并按跟注后能够赢得的底池计算价格。存储键 `riverlab-poker-v2` 和 schema 2 不变，无需数据迁移。

## 玩家可见的变化

- 跟注按钮、牌桌跟注标注，以及新记录的复盘上下文，显示应付跟注。这个金额是当前下注差额和玩家剩余筹码中的较小值。短码面对更大的全下时，看到的是自己付得出的金额。
- 即时底池赔率等于应付跟注除以跟注后该玩家有资格赢得的底池。落在这些底池里的已弃牌筹码计入；该玩家赢不到的边池，以及结算时退回的无人跟注筹码，不计入。行动提示、跟注评分和 AI 的底池赔率决策使用同一价格。
- 总底池标注、下注金额和结算不变。玩家能够补齐下注时，普通跟注和过牌仍使用原来的价格。

## 兼容性

存储 schema `2` 和 `riverlab-poker-v2` 不变。旧的复盘和备份仍然有效，包括当时记下的名义缺口大于实际投入的记录。无需数据迁移。清理站点数据或更换访问地址前，先导出完整的浏览器备份。

参见[更新记录](../../CHANGELOG.md)、[文档索引](../README.md)、[用户指南](../user/README.zh-CN.md)和 [Agent 指南](../agent/README.zh-CN.md)。

这是源码发布，不是生产部署。单活跃标签页存储和未做真机 iOS 认证的限制仍然存在。胜率估计和跟注评分仍是训练启发式，不是求解器结论。

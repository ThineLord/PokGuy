# PokGuy 0.3.3

[English](0.3.3.md) · [简体中文](0.3.3.zh-CN.md) · [更新记录](../../CHANGELOG.md)

发布于 2026-11-26。本补丁收录了本地扑克训练器已合入主线的九项修复。

## 牌桌与复盘

- 跟注控件显示当前筹码实际能支付的金额。底池赔率按实际承担风险的筹码和有资格争夺的底池计算，并计入这些池里弃牌玩家已投入的筹码。提示、跟注评价与 AI 决策采用同一价格。[#21](https://github.com/ThineLord/PokGuy/pull/21)
- 回放从第一次行动前开始，每次行动只播放一次，最终公共牌在对应步骤揭晓。切换牌局会重置播放进度。[#26](https://github.com/ThineLord/PokGuy/pull/26)
- 到了河牌，或玩家已拿到皇家同花顺时，预估补牌数显示为零。更早街道的听牌仍沿用原有估算方法。[#29](https://github.com/ThineLord/PokGuy/pull/29)
- 多个座位同名时，回放、摊牌和底池分配会用该手牌记录的位置区分玩家。若生成的标签与自定义名字重合，则追加座位号。[#35](https://github.com/ThineLord/PokGuy/pull/35)

## 设置、存档与对手

- 数值设置允许逐字输入。按回车或移开焦点会保存合法数值，输入无效则恢复已保存的值。[#30](https://github.com/ThineLord/PokGuy/pull/30)
- 只有最后选中的备份可以确认恢复。取消预览后，先前仍在读取的文件也会失效。[#25](https://github.com/ThineLord/PokGuy/pull/25)
- 普通保存会先检查其他标签页已经写入的数据。兼容的编辑会合并；遇到冲突时保留已保存的副本，当前页可导出尚未保存的修改。确认整份恢复仍会替换本地数据。同时写入没有锁，建议只在一个活动标签页打牌。[#32](https://github.com/ThineLord/PokGuy/pull/32)
- 对压力弃牌、筹码深度感知和牌面结构感知这三个已有滑块，现在会在相应情形影响 AI 的边缘决策。[#34](https://github.com/ThineLord/PokGuy/pull/34)
- 对手档案分别显示已记录手数和含初始值的 VPIP、PFR、AF 估算。没有记录手数时显示空状态。[#36](https://github.com/ThineLord/PokGuy/pull/36)

已有牌局和备份可继续使用。浏览器数据键为 `riverlab-poker-v2`，存储结构版本为 `2`，完整备份格式版本为 `1`。本次发布源码。iPhone 和 iPad 真机表现仍需单独验证。

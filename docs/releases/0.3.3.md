# PokGuy 0.3.3

[English](0.3.3.md) · [简体中文](0.3.3.zh-CN.md) · [Changelog](../../CHANGELOG.md)

Released 2026-11-26. This patch brings nine previously merged fixes to the local poker trainer.

## At the table and in review

- Call controls show what the stack can pay. Pot odds use the portion at risk and the pots the caller can win, including eligible folded contributions. Hints, call grading and AI decisions use this price. [#21](https://github.com/ThineLord/PokGuy/pull/21)
- Replay starts before the first recorded action, plays each action once and reveals the final public runout at the correct step. Selecting another hand resets playback. [#26](https://github.com/ThineLord/PokGuy/pull/26)
- The trainer hides the estimated-outs readout on the river and for a made royal flush. Estimates on earlier streets still use the trainer's draw heuristic. [#29](https://github.com/ThineLord/PokGuy/pull/29)
- Replay and showdown use the stored seat position to distinguish players with the same name, including pot awards. If the resulting label matches a custom name, the seat number distinguishes them. [#35](https://github.com/ThineLord/PokGuy/pull/35)

## Settings, saves and opponents

- Numeric settings retain partial input while typing. Enter or leaving the field commits a legal value. Invalid input restores the saved amount. [#30](https://github.com/ThineLord/PokGuy/pull/30)
- Only the most recently selected backup can be confirmed. Cancelling the preview discards any earlier file read still in progress. [#25](https://github.com/ThineLord/PokGuy/pull/25)
- Ordinary saves check data already written by another tab. Compatible edits merge. On conflict, the saved copy is preserved and the current tab can export its unsaved changes. Confirming a full restore still replaces the local dataset. Use one active tab for play because simultaneous writes have no lock. [#32](https://github.com/ThineLord/PokGuy/pull/32)
- The existing fold-to-pressure, stack-awareness and board-texture sliders now affect marginal decisions in their respective situations. [#34](https://github.com/ThineLord/PokGuy/pull/34)
- Opponent profiles distinguish the recorded hand count from VPIP, PFR and AF estimates that include starting values. A profile with zero recorded hands shows an empty state. [#36](https://github.com/ThineLord/PokGuy/pull/36)

Existing hands and backups remain compatible. The browser data key is `riverlab-poker-v2`, the storage schema is `2` and full backups use format `1`. This release publishes the source. Physical iPhone and iPad behavior requires separate verification.

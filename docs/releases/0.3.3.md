# PokGuy 0.3.3

[English](0.3.3.md) · [简体中文](0.3.3.zh-CN.md) · [Changelog](../../CHANGELOG.md)

2026-11-25. This patch shows the chips a player can actually commit when calling, and prices that call from the pots they can win. Saved-data key `riverlab-poker-v2` and storage schema 2 are unchanged. No data migration is required.

## Player-visible changes

- Call controls, the table call label, and newly recorded review context show the payable call. That amount is the gap to the current bet, capped by the player's remaining stack. A short stack facing a larger shove sees the smaller amount.
- Immediate pot odds are that payable call divided by the pots the player can win after calling. Folded players' chips in those pots count. Side pots above the player's reach, and chips that will be returned uncalled, do not. Action hints, call grading, and the AI's pot-odds decision use this same price.
- The total pot label, betting amounts, and settlement are unchanged. An ordinary call or check, where the player can match the bet, keeps the previous price.

## Compatibility

Storage schema `2` and `riverlab-poker-v2` are unchanged. Older reviews and backups stay valid, including records that stored a nominal gap larger than the chips actually committed. No data migration is required. Export a full browser backup before clearing site data or changing the site's address.

See the [changelog](../../CHANGELOG.md), [documentation index](../README.md), [user guide](../user/README.md), and [agent guide](../agent/README.md).

This is a source release, not a production deployment. Single-active-tab storage and physical-iOS verification limits remain. The equity estimate and call grade remain training heuristics, not a solver result.

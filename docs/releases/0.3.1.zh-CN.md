# PokGuy 0.3.1

[English](0.3.1.md) · [简体中文](0.3.1.zh-CN.md) · [更新记录](../../CHANGELOG.md)

发布日期：2026-11-09。本补丁处理剩余依赖公告，并精简仓库展示与组织。扑克规则、存储键和 schema 2 均不变。

## 依赖问题修复

- 升级到受支持的 vinext 1.0.1 / plugin-rsc 0.5.34，配套 OG 1.0.3、Satori 0.33.5 及上游 Node／Worker 的 WASM、字体兼容修复；React 保持 19.2.8。
- 将 minimatch 11.0.1 定向用于 typescript-eslint，将 fflate 0.7.5 定向用于 Satori，移除已无对应依赖的 image-size 覆盖。锁定依赖图在官方 registry 审计中为 **0 条漏洞**。
- CI 新增 moderate 及以上审计门禁和实际依赖回归：解析器匹配、受限进程内的恶意 glob、畸形 ZIP64 拒绝，以及 Node／Worker 生产构建的 PNG 解码和非法 SVG 样式拒绝。
- 开发和构建采用上游支持的 Vite 命令，明确保持 3000 端口，占用时直接报错，不悄悄换端口。
- 修正摊牌测试样本，让指定牌面保证被断言的唯一赢家，避免合法平分底池被误判为失败。
- 手机端浏览器检查改为等待实际滚动布局，保留原有视口和触控尺寸标准；CI 失败时保存 trace 和截图，便于定位问题。

## 更简洁的仓库首页

- 根目录受跟踪项从 **28 项减到 19 项**。页面和 Worker 归入 `src/`，测试配置归入 `tests/`，构建工具归入 `scripts/`；Prettier 与 PostCSS 配置合入 `package.json`。
- 显式指定 `src/` 应用根目录，避免旧工作区残留的空 `app/` 目录遮挡页面。
- 删除未使用的模板认证代码、三个 SVG 和空的 Next 配置，保留必要的 Vite／TypeScript／ESLint 入口及托管集成。
- 旧任务状态和报告副本改为固定 v0.3.0 历史链接；Git 历史和早期发布证据仍可访问。
- 中英文首页分别保持简洁，各展示一张真实训练桌截图；详细流程截图留在用户文档。

## 升级与验证

使用 Node 22，执行 `npm ci` 后运行 `npm run dev`。文件整理后，日常 npm 命令保持可用。清理站点数据或更换访问地址前先导出完整浏览器备份；此次无需存储迁移或清空牌局数据。

参见[安全评估](../development/SECURITY_0.3.1.md)、[验收记录](../development/ACCEPTANCE_0.3.1.md)和[开发命令](../development/README.md)。GitHub Release 中提供最终 PR 与合并后主分支的 CI 证据。

这是源码发布，不是生产部署。0 条审计结果对应当日公告数据库，不代表软件绝无漏洞。单活跃标签页存储和未做真机 iOS 认证的限制仍然存在。

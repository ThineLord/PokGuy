# PokGuy 0.2.0

[English](0.2.0.md) · [简体中文](0.2.0.zh-CN.md) · [更新日志](../../CHANGELOG.md)

发布日期：**2026-11-09**。本版本为已有扑克训练器建立清晰的仓库结构和持续的版本管理方式。

## 本次修改

- 精简项目首页，将中英文 README 分开，补充项目简介与快速启动步骤。
- 分别提供中英文用户 README 与 Agent README。Codex 负责组织和实施，独立 subagents 负责 review 和合并，流程不调用 bots。
- 设计文档统一放入 `docs/architecture/`；有日期的审计、任务和测试记录保留在 `docs/archive/`。
- 新增发布规范、PR 模板、Node 22 版本提示，以及版本元数据、发布文档和本地 Markdown 文件链接的自动检查。

## 纳入版本基线的已有功能

main 分支此前已包含 2–9 人现金桌、可配置 AI、场景训练、牌局复盘和统计、中英文界面，以及浅色／深色／跟随系统外观。0.2.0 收录这些已有功能，不把它们描述成本次新实现。

## 兼容性与限制

- 本次没有修改扑克逻辑、运行界面、依赖版本或部署配置。
- 浏览器数据仍使用格式 2 和现有 `riverlab-poker-v2` 键，不需要迁移。升级前可在设置中备份浏览器数据。
- AI 建议属于近似训练反馈，不是 GTO。没有真钱功能、完整锦标赛管理、自动跨设备同步或离线 PWA。
- 刷新不会恢复进行中的手牌；多个标签页可能互相覆盖存储，存储写入失败尚无专门提示界面。
- 本次整理未重新验证实体 iPhone/iPad 或线上生产环境。
- [PR #2](https://github.com/ThineLord/PokGuy/pull/2) 的依赖与 Worker 图片绑定修改未纳入本版本。本次发布不代表依赖安全问题或独立图片路由问题已经解决，也不证明没有安全公告。

## 发布证据

[GitHub Release](https://github.com/ThineLord/PokGuy/releases/tag/v0.2.0) 会在发布门禁通过后记录合并后的源码提交、已审查 PR 和 CI 证据。必要门禁包含版本／链接校验、格式、lint、类型检查、单元测试、生产构建和 Chromium E2E。归档中的历史测试数不能作为本版本证据。发布此源码版本不代表线上部署已验证。

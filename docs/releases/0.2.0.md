# PokGuy 0.2.0

[English](0.2.0.md) · [简体中文](0.2.0.zh-CN.md) · [Changelog](../../CHANGELOG.md)

Release date: **2026-11-09**. This release establishes a clear repository layout and regular version management for the existing poker trainer.

## Changes in this release

- A concise project home with separate English and Chinese READMEs, a project introduction and quick-start instructions.
- Separate bilingual user and agent READMEs. Codex coordinates implementation; independent subagents review and merge. No bots are part of the workflow.
- Design documentation grouped under `docs/architecture/`; dated audit, task and testing records preserved under `docs/archive/`.
- A release policy, PR template, Node 22 hint and automated checks for version metadata, release documents and local Markdown file links.

## Existing features included in this baseline

The main branch already contained 2–9 seat cash tables, configurable AI, scenario practice, hand review and statistics, Chinese/English UI, and light/dark/system appearance. Version 0.2.0 includes those features; this release does not claim to implement them anew.

## Compatibility and limits

- No poker logic, runtime UI, dependency versions or deployment configuration changed in this release.
- Browser storage remains schema 2 with the existing `riverlab-poker-v2` key; no migration is needed. Back up browser data through Settings before upgrading.
- AI advice is approximate training feedback, not GTO. There is no real-money play, full tournament manager, automatic cross-device sync or offline PWA.
- Reloading does not restore an in-progress hand. Multi-tab storage writes can overwrite one another, and storage write failures do not have a dedicated UI.
- Physical iPhone/iPad and hosted production behavior have not been revalidated for this organizational release.
- Dependency and Worker image-binding changes in [PR #2](https://github.com/ThineLord/PokGuy/pull/2) are excluded. This release does not resolve or certify the absence of dependency advisories or the separate image-route issue.

## Release evidence

The [GitHub Release](https://github.com/ThineLord/PokGuy/releases/tag/v0.2.0) records the merged source commit, reviewed PR and CI evidence after the publication gates pass. Required gates are release metadata/link validation, formatting, lint, typecheck, unit tests, production build and Chromium E2E. Historical test counts in the archive are not evidence for this version. Publishing this source release does not claim a verified production deployment.

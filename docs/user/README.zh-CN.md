# PokGuy 用户 README

[English](README.md) · [简体中文](README.zh-CN.md) · [项目首页](../../README.zh-CN.md)

PokGuy 用于练习德州扑克并复盘自己的决策。应用通过本地 Web 服务启动，牌局运行与记录保存由浏览器处理。

## 开始一次练习

1. 按[首页步骤](../../README.zh-CN.md#本地启动)启动应用。
2. 在牌桌选择 2–9 人场并开启新桌。仅修改人数选项不会打断当前手牌；开启新桌会重置筹码。
3. 轮到你时选择弃牌、过牌、跟注、下注、加注或全下。应用会校验合法尺度，并在手牌结束后解释结算。
4. 在场景构建器选择位置、筹码、底牌和起始街。返回现金桌时，会恢复本次会话保留在内存中的现金桌状态。
5. 在历史中回放最近牌局、添加笔记，筛选需要复查的决策。统计用于观察练习情况，小样本可能产生误导。

桌面端可用 `F/K/C/R/A` 执行弃牌／过牌／跟注／加注／全下；仅在对应动作可用且未编辑输入框时生效。

## 设置与数据

设置包含 AI 个性、训练提示、语言、浅色／深色／跟随系统外观、牌背和动画速度。八种 AI 个性提供不同打法倾向；它们的反馈和 Monte Carlo 估算只是近似，不是求解器建议。

设置、统计、笔记和最近 100 手牌局保存在浏览器 LocalStorage。可在设置中导出 JSON 备份，需要时在另一个浏览器导入。不同设备、浏览器和站点地址的数据相互独立；更换端口也可能改变存储来源。清除站点数据会删除记录。刷新页面会开始新的现金桌会话，不会恢复进行中的手牌。

应用版本与数据格式 v2 独立管理。升级到 0.2.0 不需要迁移数据。建议升级前例行导出备份，并将导出文件保存在公开仓库以外。

## 同一 Wi-Fi 的手机或平板

在电脑上运行：

```bash
npm run dev:lan
```

让两个设备连接同一可信 Wi-Fi，在移动浏览器中打开终端显示的网络地址。停止服务前，该开发服务会向此网络开放。记录不会自动同步，需要时手动导入导出。

## 当前限制

- 只支持现金桌与单手训练，没有完整锦标赛管理、真人匹配或真钱功能。
- AI 基于未知牌采样和训练启发式，不提供对手范围求解、GTO 或收益保证。
- 没有自动云同步、可安装离线 PWA 或声音素材；声音设置为后续预留。
- 浏览器存储可能失败，多个标签页可能覆盖彼此最后保存的数据。建议只保留一个活动标签页并定期备份。
- 响应式浏览器测试不等于实体 iPhone/iPad 验证；托管部署有单独的验证边界。

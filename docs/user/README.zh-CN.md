# PokGuy 用户 README

[English](README.md) · [简体中文](README.zh-CN.md) · [项目首页](../../README.zh-CN.md)

PokGuy 用于练习德州扑克并复盘自己的决策。应用通过本地 Web 服务启动，牌局运行与记录保存由浏览器处理。

## 开始一次练习

1. 按[首页步骤](../../README.zh-CN.md#本地启动)启动应用。
2. 在牌桌选择 2–9 人场并开启新桌。仅修改人数选项不会打断当前手牌；开启新桌会重置筹码。
3. 轮到你时选择弃牌、过牌、跟注、下注、加注或全下。应用会校验合法尺度，并在手牌结束后解释结算。
4. 在场景构建器选择位置、筹码、底牌和起始街。返回现金桌时，会恢复本次会话保留在内存中的现金桌状态。
5. 在历史中回放最近牌局、添加笔记，筛选需要复查的决策。统计用于观察练习情况，小样本可能产生误导。

桌面端可用 `F/K/C/R/A` 执行弃牌／过牌／跟注／加注／全下；仅在对应动作可用且未编辑输入框时生效。

## 设置与数据

设置包含 AI 个性、训练提示、语言、浅色／深色／跟随系统外观、牌背和动画速度。八种 AI 个性提供不同打法倾向；它们的反馈和 Monte Carlo 估算只是近似，不是求解器建议。

设置、统计、笔记、最近 100 手牌局和最多 500 条训练记录保存在 LocalStorage。不同设备、浏览器和站点地址的数据独立；更换端口也会改变存储来源。清除站点数据会删除记录。刷新会开始新现金桌会话，不恢复进行中的牌局。

### 备份与恢复

1. 打开 **设置 → 导入与导出**，点击 **导出完整备份**，将 JSON 保存在公开仓库之外。
2. 在目标浏览器点击 **导入备份或旧设置**，选择该文件（最多 10 MB）。
3. 检查 **恢复预览** 中的玩家、牌局、笔记和点评数量。取消不会改变现有数据。
4. **确认恢复** 会替换保存的数据和偏好，并开始新牌局。若想保留目标设备原数据，请先导出它的备份。

完整备份包含设置、AI 配置与习惯、全部保留的已完成牌局、现金／场景／旧版统计、笔记、点评、语言和主题；不包含进行中的牌局及内存中的现金桌／场景返回快照。单独的 **导出牌局记录** 供查看记录，不是可完整恢复的备份。旧设置导出文件会被明确识别，仅替换设置与配置，保留当前牌局和最新记录。

保存失败时，**更改尚未保存** 警告会持续显示。释放空间后可 **重试保存**，或关闭前 **导出完整备份** 救援内存内容。恢复失败会保留当前内存中的数据；若回滚异常，救援警告会保留到完整重试成功。浏览器离开警告并非绝对可靠，请以实际导出为准。

### 统计、点评与移动端详情

统计页可选择 **现金桌**、**场景训练** 或 **旧版混合统计**。仅凭最近 100 手无法可靠重建全部旧历史，因此旧总量单独保留，不参与新现金桌 AI 适应。VPIP/PFR 仅计入实际获得翻牌前行动的手牌，3-bet／持续下注按实际机会计算。点评数量对应所选模式中保留的牌局。

**未充分评估** 表示现有启发式不足以作正面或负面结论。新点评展示行动当时的筹码、跟注价格和粗略胜率；同额全押与下注使用统一尺度规则。这些提醒仍不构成最优策略证明。

点击任意座位可查看完整姓名、公开筹码、位置和状态。关闭或按 Esc 会返回焦点；暗牌保持隐藏，详情打开时暂停扑克快捷键。

应用版本与存储格式 v2 独立管理。0.3.0 增加兼容的统计字段，保留旧总量；完整备份另有独立格式版本，当前为 1。

## 同一 Wi-Fi 的手机或平板

在电脑上运行：

```bash
npm run dev:lan
```

让两个设备连接同一可信 Wi-Fi，在移动浏览器中打开终端显示的网络地址。停止服务前，该开发服务会向此网络开放。记录不会自动同步，需要时手动导入导出。

## 当前限制

- 只支持现金桌与单手训练，没有完整锦标赛管理、真人匹配或真钱功能。
- AI 基于未知牌采样和训练启发式，不提供对手范围求解、GTO 或收益保证。
- 没有自动云同步、可安装离线 PWA 或声音素材；声音设置为后续预留。
- 浏览器存储可能失败，多个标签页可能覆盖彼此最后保存的数据。建议只保留一个活动标签页并定期备份。
- 响应式浏览器测试不等于实体 iPhone/iPad 验证；托管部署有单独的验证边界。
